IndianOS

A browser-based desktop operating system inspired by India, built with **HTML**, **CSS**, and **JavaScript** for the **Hack Club Stardance – WebOS 1 Mission**.

---

## ✨ Features

* 🚀 Boot Screen with startup animation
* 🖥️ Interactive Desktop Interface
* 📋 Start Menu
* 🪟 Multiple Draggable Windows
* 📁 Files Application
* 📝 Notes Application
* 🧮 Calculator
* 🕒 Live IST Clock
* 🔔 Notification Toasts
* 🖱️ Double-click to Maximize/Restore Windows
* ℹ️ About IndianOS Window
* 🎨 Clean, responsive UI inspired by a desktop operating system

---

🛠️ Built With

HTML5
CSS3
Vanilla JavaScript
