#Indian OS
A browser-based desktop operating system inspired by India, built using **HTML**, **CSS**, and **JavaScript** for the Hack Club **WebOS 1 Mission**.

## ✨ Features

* 🚀 Boot Screen
* 🖥️ Desktop Interface
* 📋 Start Menu
* 🪟 Multiple Draggable Windows
* 📁 Files App
* 📝 Notes App
* 🧮 Calculator
* 🕒 Live IST Clock
* 🔔 Notification Toasts
* 🪟 Double-click to Maximize/Restore Windows
* ℹ️ About IndianOS

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

## 🚀 Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.

Or visit the live demo if deployed with GitHub Pages.

## 🎯 Project Goal

The objective of this project was to create an original browser-based desktop operating system with draggable windows while exploring frontend development concepts such as:

* DOM Manipulation
* Event Handling
* Window Management
* Responsive UI Design
* CSS Animations
